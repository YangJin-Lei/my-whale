my-whale v0.1.0
GitHub 打开 Web / PWA

本地优先的 DeepSeek 第三方客户端

纯静态直连 DeepSeek 官方 API，零后端不中转。支持引导配 Key 与余额安全排查、自定义人设、全局与单对话局部记忆隔离，以及历史对话 ZIP v3 无损迁移。

立即打开 Web / iOS PWA 版 下载 Android APK / 桌面端 (Releases) 查看开源仓库
iPhone / iPad 安装方式（PWA）： 使用 Safari 点击上方「立即打开 Web / iOS PWA 版」进入应用后，点击底部「分享」图标 → 选择「添加到主屏幕」，即可像原生 App 一样全屏运行，所有数据仅保存在你设备的本地浏览器中。

核心能力

Web、iOS PWA、Android APK 与 Tauri 桌面端数据格式 100% 互通

引导配 Key 与余额监测

新手一站式获取、粘贴并校验 DeepSeek API Key；支持赠金/充值余额查询、官网用量快捷跳转与退出 Key。

自定义人设与试聊机制

支持上传头像图片、设定提示词与默认推理/搜索开关，支持试聊与一键保存到左侧对话列表。

全局 + 单对话局部记忆

「关于我」与长期记忆支持后台自动提炼；单个对话可独立记录局部记忆或开启「仅使用本对话局部记忆」。

历史对话无损迁移

兼容 DeepSeek 网页版导出的历史对话 ZIP（v3），保留分支、图片附件，以及人设快照与记忆备份。

界面演示

从首次引导、记忆管理到主对话界面的完整体验

1. 首次启动引导与历史迁移
支持引导申请并粘贴 API Key，并在首屏直接导入历史对话压缩包。
2. 记忆设置与后台提炼
管理全局「关于我」与记忆条目，支持搜索、分类、即时提炼与导入导出。
3. 自定义人设与局部隔离
支持自定义人设切换、无痕会话及单对话内局部记忆隔离控制。
