核心能力

Web / iOS PWA、Android APK 与 Tauri v2 桌面端数据格式 100% 互通

引导配 Key 与余额监测

新手一站式获取、粘贴并校验 DeepSeek API Key；支持赠金/充值余额查询、官网用量快捷跳转与退出 Key。

自定义人设与试聊机制

支持上传头像图片、设定提示词与默认推理/搜索开关，支持试聊与一键保存到左侧对话列表。

全局 + 单对话局部记忆

「关于我」与长期记忆支持后台自动提炼；单个对话可独立记录局部记忆或开启「仅使用本对话局部记忆」。

历史对话无损迁移

兼容 DeepSeek 网页版导出的历史对话 ZIP（v3），保留分支、图片附件，以及人设快照与记忆备份。

引导、记忆与迁移界面

覆盖从首次配置 API Key 到历史归档导入与记忆提炼的日常高频场景

1. 首次启动引导与历史迁移
引导申请并粘贴 API Key，支持直接在首屏导入历史对话压缩包。
2. 记忆设置与后台提炼
管理全局「关于我」与记忆条目，支持搜索、分类、即时提炼与导入导出。
3. 导入历史后的完整上下文
导入历史归档后无缝延续对话上下文，支持「记住这条」一键沉淀全局或局部记忆。
